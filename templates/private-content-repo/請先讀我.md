# 初級團每週內容（私人）

呢個專案要保持 **Private（私人）**。

每週開一個資料夾，例如 `weeks/2026-10-11/`：

- `week.json`：文字
- `01.jpg`、`02.jpg`：相片，放喺同一個資料夾。每週最多 80 張
- 短片可選：`clip1.mp4`，每週最多 2 段。請用 mp4。詳情睇公開專案 README

改完之後，去公開專案 fct-junior → Actions →「發佈加密網站」→ Run workflow。

詳細步驟喺公開專案嘅 README。

## 司事輪值表唔好放喺呢度

輪值表唔係每週內容。請將 JPEG 放喺 Google Drive「26-27_初級團網站資料」入面嘅「2026_司事輪值表」，唔好上傳來呢個私人倉。

如果「26-27_初級團網站資料」已經分享俾服務帳戶，新資料夾通常會一齊俾佢睇。如果發佈後輪值表頁顯示「未有圖片」，請再對「2026_司事輪值表」撳共用，加入服務帳戶 JSON 入面嘅 `client_email`，權限揀檢視者。唔好把 JSON 或者密碼寫入呢個專案。

自己電腦試睇可以放 `private-pages/steward-roster.jpg`（呢個資料夾不會 commit）。詳情睇公開專案 README。
